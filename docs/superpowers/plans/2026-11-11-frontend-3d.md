# SAFE — Painel 3D "O Olhar": Plano de Implementação

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Refazer a camada visual do painel do SAFE como experiência 3D guiada por scroll, mantendo toda a função de gestão.

**Architecture:** Um `canvas` WebGL fixo (Three.js local) atrás do conteúdo, controlado por uma fachada `cena` com quatro métodos; as views continuam donas do DOM e apenas informam à cena o progresso da jornada, o enquadramento da rota e pulsos de evento. Sem WebGL ou com movimento reduzido, a fachada é inerte e o CSS assume.

**Tech Stack:** HTML/CSS/JS (ES modules, sem build), Three.js 0.160.0 vendorizado, GLSL, FastAPI/pytest para o teste de serviço.

**Spec:** `docs/superpowers/specs/2026-11-11-frontend-3d-design.md` (e, para a parte funcional, `2026-11-10-frontend-design.md` §3, §6.2–6.4, §7, §8).

## Global Constraints

- Branch `front`. **Não commitar** sem pedido do usuário; cada task termina em checkpoint.
- Backend intocado: nada fora de `software/api/app/assets/painel/`, `software/api/tests/test_painel.py`, `software/README.md` e `docs/superpowers/`.
- Three.js só de `vendor/three.module.min.js` (three@0.160.0), via importmap local `"three": "./vendor/three.module.min.js"`. Nenhuma URL do site de referência.
- Nenhum dado da API entra por `innerHTML` (inclusive em `letras.js`).
- Cores dos estados: Aguardando `#7aa7d9`, Validando `#f5b942`, Aceito `#4ade80`, Negado `#f8615a`, Neutro `#7fd4e6`.
- Fontes: Italiana, Outfit (300/400/600), JetBrains Mono (400/500).
- Suavizações por quadro: scroll 0,06; câmera 0,05; mouse 0,05; anel do cursor 0,2. Atraso por letra 0,035 s. Transição de rota 180 ms.
- Jornada: 700vh; seis momentos com as faixas da spec §5.
- Sem `user-select: none` global; campos de texto com cursor e seleção nativos.
- API de verificação local usa banco temporário (`DATABASE_URL` no scratchpad), nunca `software/api/safe.sqlite3`.

### Task 5: Painel — jornada por scroll

- Produces: `render(container) → cleanup`. O `cleanup` cancela o laço de animação, remove listeners, desfaz a assinatura de saúde, limpa `--acento` e esvazia `#progresso`.

Textos dos momentos (título / corpo), exatamente:
0. "Acesso pelo olhar" / "O SAFE reconhece rostos em um Raspberry Pi 5 e traduz o resultado em dois sinais elétricos, que uma máquina de estados transforma em acesso liberado ou negado."
1. "Aguardando" / "S = 0 · V = 0. A câmera está ativa e nenhum rosto está em processamento."
2. "Validando" / "S = 1 · V = 0. Um rosto foi detectado. A identidade só é confirmada após 5 quadros coincidentes."
3. "Aceito" / "S = 0 · V = 1. Pessoa reconhecida. O circuito libera o acesso."
4. "Negado" / "S = 1 · V = 1. Pessoa desconhecida ou não confirmada. O acesso permanece fechado."
5. "Operação" / passos "Cadastrar pessoa", "Enviar fotos", "Treinar o modelo no Pi" (`python treinar.py` com botão Copiar) e tabela de pinos S=GPIO 17/pino 11, V=GPIO 27/pino 13, CLK=GPIO 22/pino 15.
